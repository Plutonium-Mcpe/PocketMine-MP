# 5.118.2

## Fixes
- Fixed held items not rendering on other players. Skins with no geometry data of their own were sent a hand-written humanoid model that lacked the `rightItem`/`leftItem` bones the client attaches held items to; the geometry name is now resolved by the client instead.

# 5.118.3

## Fixes
- Sculk sensors, sculk shriekers and sculk veins can be placed and saved again. Their block state mappings were dropped when the block serializers were unified, so any attempt to serialize them threw `BlockStateSerializeException`.
- Fixed a crash when using an anvil that was broken or replaced while its window was still open.
- Fixed the player briefly teleporting to 0,0,0 when leaving a bed on 1.26.x, and sleep is now aborted if the bed is destroyed underneath the player. (upstream)
- Book edit packets with negative page numbers are now rejected instead of corrupting the book. (upstream)
- The resource pack completion handler can no longer be triggered more than once by a client. (upstream)
- Legacy inventory transactions with no window ID are now rejected instead of failing later. (upstream)

## Internal
- Removed leftover debug logging that appended to `/tmp/pluto_pkt_dump.log` on every login and crafting request, and built the player skin twice on login.
- All CI checks pass again: code style, PHPStan, PHPUnit, codegen and integration tests.
